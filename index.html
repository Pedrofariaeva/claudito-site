Claudito is a free, open-source command-line assistant for academic research — no web app, no account, no cloud. It harvests papers from publishers, screens and organises your BibTeX references, and builds your LaTeX, Word and PDF documents — inside your project folder, under your control.

Install

One line. The installer tries GitHub first and falls back to the GitLab mirror automatically — use whichever line matches your platform.

Windows (PowerShell)

[Net.ServicePointManager]::SecurityProtocol='Tls12'; Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process -Force; try { irm https://github.com/Pedrofariaeva/claudito-releases/releases/download/vX.Y.Z/install.ps1 | iex } catch { irm https://gitlab.com/Pedrofariaeva/claudito-releases/-/raw/main/install.ps1 | iex }

Replace vX.Y.Z with the version shown on the latest release page.

macOS / Linux (Terminal)

(curl -fsSL https://github.com/Pedrofariaeva/claudito-releases/releases/download/vX.Y.Z/claudito-external-vX.Y.Z-macos.tar.gz -o claudito.tar.gz || curl -fsSL https://gitlab.com/Pedrofariaeva/claudito-releases/-/raw/main/claudito-macos.tar.gz -o claudito.tar.gz) && tar -xzf claudito.tar.gz && cd claudito-external-vX.Y.Z && ./install.sh

Same here — vX.Y.Z comes from the latest release page.

The first 10 minutes

Claudito ships with a guided tutorial: it tells you what to type, then checks that it actually happened. This is the shape of a first run.

  1. Open a terminal inside your research folder and type clt. Claudito starts a session there.
  2. Type new project. Claudito creates the project structure: Project plan/, Documents/, references/.
  3. Drop your abstract into Documents/abstract.txt. Claudito confirms the project now has a working abstract.
  4. Type harvest with your topic. Claudito searches the publisher databases and downloads the papers into references/, organised by theme, with a BibTeX entry for each.
  5. Edit Project plan/Project.txt — the master document. Lines starting with // are private notes that never appear in the output.
  6. Type build. Claudito compiles the plan into PDF, Word and LaTeX under latex/.

What it does

Built by a working researcher, for the parts of research that eat your evenings.

Harvest the literature

Searches publisher databases (Scopus, ScienceDirect, Springer, IEEE, ACM, Wiley…) and downloads papers into a library organised by theme — not a downloads-folder pile.

Tame the references

Every paper gets a clean BibTeX entry. Duplicates are merged, junk is screened out, and the curated shortlist stays separate from the harvested pool.

One master document

Your plan, report or paper lives in a single readable text file. Claudito builds the LaTeX, the PDF and the Word file from it — always in sync, always reproducible.

Teams without tears

Invite collaborators, share the project, and sync between machines. Every session is logged; every change is archived before it happens.

A guided first run

The built-in tutorial walks you through the first project step by step and checks each step is really done — no manual required.

Free and open

No accounts, no subscriptions, no cloud lock-in. Your project stays a plain folder you can zip, git, or carry on a USB stick.
